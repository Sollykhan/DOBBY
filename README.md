# DOBBY

Assistant personnel : backend Python, application Android et interface Wear OS.

- `nexus-bridge-v02/` : backend et tests.
- `dobby-android/` : projets Android et Wear OS.
- `outputs/dobby-voix/synth_worker.py` : adaptation de synthese locale Piper. Les modeles et les environnements Python ne sont pas fournis.

La configuration personnelle, les conversations, le coffre de notes, les identifiants et les bases de donnees ne sont pas inclus. La connexion aux agents reels, la migration Linux et le stockage des identifiants Google sur Linux restent a finaliser. Les tests sont executes sans appel payant. Consulter les README de chaque composant avant utilisation.
